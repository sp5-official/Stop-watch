# ⏱️ Stop Watch Web Application

A simple and responsive stopwatch web application developed using **HTML5**, **CSS3**, and **JavaScript**.
This project was created as part of a task provided by **PRODIGY INFOTECH** during a web development internship.

🔗 **Live Demo**: https://github.com/sp5-official/Stop-watch/index.html

---

## 📖 Project Overview

The Stop Watch Web Application allows users to:

- **Start** the stopwatch to begin timing.
- **Pause** the stopwatch to halt the timing.
- **Reset** the stopwatch to clear the current time.

This tool is useful for tracking time spent on various activities like studying, workouts, or any time-bound tasks.

---

## 🧩 Key Features

- **Start, Pause, and Reset** functionalities.
- **Responsive Design**: Ensures optimal viewing on devices of various screen sizes.
- **User-Friendly Interface**: Clean layout with intuitive controls.
